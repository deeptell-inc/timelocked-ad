## (2) 個別の裁定

### (2a) A#2 と B#4 の整合 — min-ent 列は時間ロックを使わない。A は正しい

**結論（確度 88）**: A の言う通り、「joint, min-ent」列は時間ロックを使わない。しかも、ブロック間の任意の量子的共同測定に対して有効である。

**加法性の証明（A の主張を、積 cq 状態に対して独立に確認した）**。条件付き min-entropy の主形式は SDP である。

- 主問題: max Tr[Z_{AB} ρ_{AB}]、条件 Z ≥ 0 かつ Tr_A Z ≤ 𝟙_B。
- 双対問題: min Tr σ_B、条件 𝟙_A⊗σ_B ≥ ρ_{AB}。

積状態 ρ⊗ρ′ について、主問題の実行可能解は積 Z⊗Z′ で作れる（Tr_{AA′}(Z⊗Z′) = Tr_A Z ⊗ Tr_{A′}Z′ ≤ 𝟙）。双対の実行可能解は σ⊗σ′ で作れる。理由は、𝟙⊗σ ≥ ρ ≥ 0 かつ 𝟙⊗σ′ ≥ ρ′ ≥ 0 なら、異なるテンソル因子上の順序付き正作用素の積が順序を保つからである。強双対性により両者の最適値が一致するので、H_min は積状態で厳密に加法的である。ここで E は量子系でもよい。したがって、各ブロックの状態が積であり、かつ側情報にパリティ c を含めるなら、

H_min(A^S | E^S C^S) = −S·log₂ p̄,  p̄ = p_u·P_ad(c_ψ) + (1−p_u)·P_ad(c_φ)

が量子メモリ付きの Eve に対して成り立つ。P_ad は、既知の対を判別するホレボ確率（メモリを持つ Eve が実際に実行する値）であり、定理 1 はそれが非適応な共同測定でも達成されることを示す。つまり min-ent 列は、定理 1 の帰結として時間ロックの有無に依存しない。

**B#2 の限定の撤回**。B#2 の「非平滑版の加法性は独立な古典ブロックに限られる」は、この列には当てはまらない。撤回する。B#2 の残りの懸念（受理事象と PE への条件付け、S⁻ のランダム性、適応）は、min-ent 列では「スムージング／典型事象の扱い」に帰着する。ブロック間の共同測定の問題ではない。Shannon 列の問題としては残る。

**B#4 との整合**。B#4 は、同じ二状態アンサンブルでも H(A|E_quantum)=1−h((1+q)/2) と H(A|Y_Helstrom)=h((1−√(1−q²))/2) が異なる（q=1/2 で 0.189 対 0.355 ビット）と述べた。これと A の指摘は矛盾しない。同じ事実の二つの面である。

- 推測確率（min-entropy）で測ると、時間ロックの利得は厳密にゼロである（定理 1 の内容そのもの）。
- シャノンエントロピーで測ると、時間ロックの利得はホレボと accessible information の差（B#4 の 0.189 対 0.355）だけ生じる。ただし、ブロック間が積測定のときに限る。

したがって定理 1 は、「時間ロックは推測確率の意味では何も買わない」と読むのが正確である。表 I に残る時間ロック依存の効果は Shannon 列だけである。

**正味の価値（A の約 0.7 pt に新しい補正を加える）**。ログの値で比べる。

| 会計 | 値 | 時間ロック依存 |
|---|---|---|
| joint Shannon（b=7） | 18.35% | あり（ブロック間積測定の限定付き） |
| joint min-ent（b=11） | 17.66% | なし |
| Holevo（時間ロックなし Shannon、b=7） | 16.76%（`panel_variants.log` で A と一致） | なし |

時間ロックなしの最良値は 17.66% なので、正味の価値は約 0.7 pt である。post-selection を課すと、joint Shannon は 17.80%（b=7）、joint min-ent は 17.25%（b=9）または A の 17.52%（b=11）になり、差は約 0.3 pt に縮む。PE 側の信頼区間の拡大（下記 (2b) の第三項）を入れるとさらに縮む可能性が高い。T25 の 17.30%（coherent 攻撃に対して安全）との差も同程度の大きさである。

**含意**。本稿の最も強く言える肯定的結論は「時間ロックなしの集団攻撃評価（min-ent、17.5–17.7%）が T25 の EUR 評価（17.30%）より緩い」であり、時間ロックの効果ではない。T25 との比較は、解析手法の差（EUR 対直接計算）と、攻撃クラスの差（coherent 対 collective）が混ざっている。

### (2c) A#1 と B#1 — ランダム分割に対する時間ロックはどんな敵のクラスを強制するか

**1. 設定（手順の事実）**。T25 Protocol 1 では、検出記録 I、基底、強度、検定集合、並べ替え、分割、パリティが、すべて量子フェーズの後に決まる（上の「T25 Protocol 1 の確認」参照）。分割とパリティのどちらも、プローブが Eve の手元にある間は知られない。honest な側は分割を共有シードから擬似乱数で作れば、分割そのものを発表せずに済む。ブロックごとのパリティだけを発表すればよい。このとき分割の秘匿は、A1 の計算量仮定（t_comp > t_coh）だけで強制される。

**2. 強制される敵のクラス（定義）**。コヒーレンス時間を τ=t_coh とする。時刻 t_i に到着したプローブ E_i は t_i+τ までしか量子的に保持できない。Eve の操作は、各時刻に「生存集合 {E_i : t_i ≤ t < t_i+τ}」に作用する量子インストルメントの列である。出力は古典で、過去の出力すべてと独立な乱数に依存してよい。T_run+τ までは、分割、基底、検出記録、パリティ、シンドロームのいずれも知らない（最後の τ 区間のパルスだけは例外で、割合は τ/T_run）。これを「窓インストルメント敵」と呼ぶ。

**3. 命題（論証の骨子。証明は未完）**。次の条件を仮定する。(i) 分割が一様でそれまでの Eve の見るものと独立。(ii) ブロック内の順序もランダム。(iii) 状態が i.i.d. 積（untagged 回の collective 攻撃）で、ビット a_i が一様 i.i.d.。このとき、b 個のメンバーが互いに別の生存集合にあるブロックでは、記録 Y の条件付き分布が次の形に因数分解される。

P(Y | a_block) = Π_j P(y_j | a_j; 他のプローブの記録)

各因子は、プローブ j に対する実効的な POVM である（他のプローブの状態を痕跡で落としたもの）。その POVM は、他人（ストレンジャー）の出力にのみ依存する。メイトの出力には依存できない。Eve はメイトが誰か知らないからである。したがって、実効戦略は「ブロック位置について交換可能な法則を持つ、役割に無関係なランダム化積 POVM」である。

- 帰結 1: フィードフォワード（メイトの出力に依存する測定）は排除される。ストレンジャーへの依存は共有乱数と同じで、利得を生まない。
- 帰結 2: 役割依存の非同一測定は、ランダム割り当てに薄まる。
- 帰結 3: 値のサンドウィッチが成り立つ。V(同一の最適 POVM) ≤ V(役割に無関係なランダム化) ≤ V(役割ごとに最適な非適応積 POVM)。

### (2d) A の偶数 b の発見は、分割が隠れても残るか

**答え: 同一 POVM 版は残る。役割依存・フィードフォワード版は消える。**

- 手計算（独立の導出）: b=2 で、投影測定の軸をホレボ軸から角 θ だけ傾ける。ブロックの二つの投票のチャネルが p0=½(1+sin(α+θ))、p1=½(1+sin(α−θ))（α は Bloch 半角）の非対称チャネルになる。パリティ c=0 のクラスでは、同票が割れたときの決定がタイ（ホレボのとき）から有利な側に傾き、guess は δ′+|x|(2δ′−1) になる（x=(p0−p1)/2 は θ に比例、δ′=(p0+p1)/2 はホレボ値から θ² だけ下がる）。c=1 のクラスでは δ′ に戻る。二つを平均すると δ′+½|x|(2δ′−1) で、θ=0 で一次の傾きを持つ。D=0.1 の例では θ≈0.32 rad で約 0.835 になり、ホレボの 0.8143 を超える。ログの最適値 0.8454（4 出力）はこの方向と整合する。
- 物理的な原因: 偶数 b ではホレボ＋集計は常に同数投票のタイを持つ。タイが残る限り、わずかな非対称性が一次の利得を生む。奇数 b ではタイがなく、利得は θ の二次になって損失と競合する。`perprobe_opt.log` で b=3, 5, 7 が一致するのと整合する。
- 隠れた分割の下で: 同一 POVM は役割を要さない。メイトを知らなくても実行できる。フィードフォワードは消える。役割依存の非同一測定はランダム割り当てに薄まるが、同一版だけで利得の大半（0.8454 対 0.8562–0.8580）が残る。
- 帰結: 表 I と表 II の偶数 b（b=2, 4）の個別列は、min-ent（guess）会計で Eve を過小評価している。Shannon 列への影響は小さい（`perprobe_opt.log` の J_opt−J_helstrom は b=2 で最大 0.0018（D=0.23）、b=4 で最大 0.0003 程度）。見出しの b=9（奇数）は D=0.1 で変わらないが、閾値領域は未確認である。

### 必須修正三項目

1. **プロトコルの時間表を固定し、RP（T25 忠実）と CB（連続ブロック）を別の命題として分析する**。RP では、窓インストルメント敵のクラスを定義し、役割に無関係なランダム化積 POVM への還元（命題 P1）と、同時生存メンバー ≥2 のブロックを P_ad（定理 1）で信用する扱い（q の超幾何評価）を証明する。CB では、局所性と置換不変性の緊張を解く還元（エントロピー蓄積定理、またはブロック単位の post-selection の指数 16^b−1 を明示した評価）を与える。与えられないなら、CB の joint 列を「collective 攻撃・ブロック間積測定」の条件付きと明記する。
2. **会計を分離し、安全性パラメータを一本化する**。時間ロック依存のものは Shannon 列だけで、min-ent 列は時間ロックなしの集団攻撃の値である、と表に明示する。時間ロックなしの基準線（min-ent と Holevo: 16.40/16.76/15.59%）を併記する。post-selection を LHL、AEP、PE の三項すべてに課して閾値を再計算し、b を再最適化する。ε の表示を 5ε_sec/4 か ε_sec のどちらかに統一する。T25 との比較は、攻撃クラス（coherent 対 collective）をそろえて行う。「unconditional security already achieves essentially the same」と「no better analysis can exceed it」は撤回する。
3. **per-probe の主張を、証明された範囲に合わせる**。個別列を「役割に無関係な同一ホレボのベンチマーク」と明記し、偶数 b の値は役割に無関係なランダム化積 POVM の最適値で置き換える（b=2, D=0.1 で 0.8143→少なくとも 0.8454）。奇数 b=9 の閾値領域（D≈0.17–0.23）でホレボ最適性を確認する。併せて、c_φ=1 の普遍性（B#6）、「≤0.15 pt」（N=10⁸ で偽）、b=31 のアンダーフロー、旧 Fano ファイルと「1.0 pt」の出典、BWW08 への帰属と「does not help BB84 at all」（BAL11 の Shannon 利得と矛盾）を訂正する。
